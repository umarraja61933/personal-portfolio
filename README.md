# 🚀 Personal Portfolio Website

Welcome to the official repository of my personal portfolio website! This project is built to showcase my educational background, technical skills, professional work experience, and featured full-stack projects.

## 🌐 Live Demo

👉 **[View Live Portfolio Website](https://umarraja61933.github.io/personal-portfolio/)**

---

## ✨ Features & Highlights

- **Modern UI/UX Design:** Built using a fancy neon mesh color palette with glassmorphism effects.
- **Smooth Animations:** Integrated multi-dynamic CSS and JS-powered scroll reveal transitions.
- **Interactive Modals:** Detailed specification popups for featured projects with direct GitHub repository links.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- **Direct Contact Form:** Integrated with Formspree for real-time email delivery directly to my inbox.

---

## 🛠️ Tech Stack Used

- **HTML5** – For structured markup.
- **CSS3** – For styling, Flexbox, Grid, and smooth custom animations.
- **JavaScript (ES6+)** – For interactive modals, form validation, and scroll reveal effects.
